# Portfólio Pessoal — Roberta Tramontina

Projeto desenvolvido no âmbito da **Tarefa Assíncrona de Bootstrap 5**, durante a formação **Software Developer — CESAE Digital**.

## Sobre o projeto

Página web de portfólio pessoal, desenvolvida com HTML5 e Bootstrap 5, para apresentar o meu percurso, competências técnicas, projetos e certificações nas áreas de Networking, Cybersecurity e Software Development.

O objetivo da atividade é aplicar os componentes e as classes do Bootstrap na construção de uma página organizada e responsiva, sem CSS personalizado.

## Funcionalidades

- Menu de navegação responsivo com links para as secções da página;
- Apresentação pessoal e secção «Sobre mim»;
- Cards de competências em redes, cibersegurança e desenvolvimento;
- Cards de projetos com ligações externas;
- Certificações com links para as credenciais;
- Formulário de contacto com validação HTML dos campos obrigatórios;
- Rodapé com créditos e links para GitHub e LinkedIn.

## Tecnologias utilizadas

- HTML5
- Bootstrap 5.3.8 (CSS e JavaScript oficiais por CDN)
- Git e GitHub
- GitHub Pages (publicação)

Não foi utilizado CSS personalizado.

## Como executar

1. Clonar ou descarregar o repositório.
2. Abrir o ficheiro `index.html` num navegador.
3. Manter uma ligação à internet para carregar o Bootstrap através do CDN.

## Formulário

O formulário utiliza campos obrigatórios e validação HTML. Na versão demonstrativa, a submissão encaminha para `utils/success.html`. **Não existe envio real de mensagens nem armazenamento de dados.**
